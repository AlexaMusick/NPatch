## Pre-Introduction 

Fork of Rootless implementation of LSPosed framework, integrating Xposed API by inserting dex and so into the target APK.

They( sincerely invite you to join our [Telegram](https://t.me/NPatch) group to get more information and updates about NPatch.

## Supported Versions

- Min: Android 9
- Max: In theory, same with [JingMatrix/LSPosed](https://github.com/JingMatrix/LSPosed#supported-versions)

## Pre-Download

For original stable releases, please go to [Github Releases page](https://github.com/7723mod/NPatch/releases)
For original canary build, please check [Github Actions](https://github.com/7723mod/NPatch/actions)
Note: debug builds are only available in Github Actions

## Pre-Usage

+ Through jar
1. Download `npatch.jar`
1. Run `java -jar npatch.jar`

+ Through manager
1. Download and install `manager.apk` on an Android device
1. Follow the instructions of the manager app
